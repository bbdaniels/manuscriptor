Evidence verbatim

Time to deliver on NCDs

nishtar2018time · main.tex:212

Underlines carry meaning

A citation's underline is its evidence status: green the quote is verbatim in the cited paper, amber the model reported it but could not match it, red nothing found. Scanning a page tells you where your support is thin before you read a word.

Violet means computed

Every number that arrived through \input from analysis code is marked. That is your no-hardcoded-results rule made visible: an unmarked number in prose is one you typed by hand, and the page will show you that.

The source you edit is unflattened

The Source tab shows \input{...}, never the resolved value. Editing a paragraph can never silently bake a result into the manuscript, because the directive is what you are holding.

Pins show what is happening

A comment is amber while queued, blue while being addressed, green once resolved with a diff to review. Nothing changes under you without a mark in the margin.

Outside markup comes in

A reviewer's PDF or a coauthor's tracked changes are matched to paragraphs by the text they highlighted, not the page number, so the anchors survive your rewrites. Anything that cannot be placed confidently waits in a tray rather than attaching itself to the wrong sentence.

Compiling stays where you are

PDF and Word run the tools you already have, so the Word file opens in Word and the tables keep their rules. You never leave the page to find out what the manuscript looks like.

Nothing typed is ever discarded

A draft belongs to its block, not to the panel showing it. Click away, scroll off, let a file change land underneath you: the text is still there when you come back, and the paragraph carries a dot until you save or discard. The inspector rebuilds constantly, so this had to be true by construction rather than by remembering to be careful.

Three columns, three scrolls

The window never scrolls; each column does. That is what lets you hold a claim in view while reading the code behind it, and it is why a redraw has to restore three scroll positions, not one.

The inspector is pinned, not following

Scrolling away never clears what you opened. The header offers a way back to the paragraph it belongs to instead, because scrolling to check something should not throw away the thing you were checking.

Inserting is a multi-file write

A citation writes three places, a number writes three, an exhibit writes four. A text editor can only ever do the manuscript line, which is why insertion has to live in the tool rather than beside it.

There is no field for a literal number

You cannot type a result, because the only way a value enters the manuscript is as an \input of a file some script wrote. Your standing rule is enforced by there being no other door.
